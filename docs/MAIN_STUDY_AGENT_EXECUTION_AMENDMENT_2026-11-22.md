# Prospective agent-audited exploratory execution amendment

22 November 2026. This amendment is written before main-study model capture,
probe fitting or held-out outputs. It changes execution eligibility for a
**separate exploratory study**, not the original human-review protocol, labels,
fitting policy, primary estimand, splits or historical results.

## Authorization and status

The user's instruction authorizes independent agent checking and continued work:

> well check it yourself please with an independent agent to then keep going and researching deeply to make sure this is truly research grade and hypercompetitive for masters applications

The earlier human prerequisite was a prospective project protocol choice. It
was not a requirement imposed by a skill or external assessment policy. The
original `main-study-execution-freeze-v1` route still requires genuine human
records. Blank human ledgers remain blank. Agent answers never become student
or independent-human acceptances.

The new route uses the distinct schema
`main-study-agent-exploratory-freeze-v1`, records
`research_status=agent_audited_exploratory`,
`human_review_complete=false`, and `confirmatory_result=false`.
These markers propagate into capture provenance, fit settings and analyses.
Real model observations are empirical results; they are not a completed human
validation or a confirmatory result under the original protocol. Report this
amendment and audit limitations prominently with results.

## Semantic checking before capture

An agent that did not author the bank reads the blinded representative packet,
all 154 narrative groups and normalized paths. It saves independent literal
YES/NO/UNSURE answers for all 736 prompts, prompt hashes, prose assumptions,
case issues, transformation checks, actual timestamp and limitations **before**
answers are compared against formal labels. The audit must identify its reviewer
as an agent. No model scores or generated answers are supplied to the reviewer.

The validator checks the bank and exact packet bindings, complete unique answer
coverage, transformation declarations and agreement with the formal target.
Any UNSURE, mismatch, unresolved case issue or blocker stops execution. Preserve
the independent source file; never overwrite answers to manufacture agreement.
Revisions require an explicitly versioned bank/audit and new freeze before runs.
Passing this gate establishes consistency between one agent's interpretations
and the formal labels. It cannot authenticate independence or replace human
semantic validation. Common model or author blind spots remain possible.

The packet covers normalized paths and all narratives; omitted factorial cells
are justified by declared complement/world/name transformations. Do not claim
that every one of the 5,888 expanded prompts was independently read.

## Prospective source and fitting controls

Before capture the amendment must be tracked in Git's index. A fresh train/dev
freeze binds its hash, exact user instruction, independent audit and packet,
bank, policies and all capture/fitting/analysis source files. Fresh preparations
must use those current sources; older preparations cannot silently resume.

Capture train/development rows first. Freeze both pinned models' complete
train/dev fit bundles before authorizing any test capture. A separate fresh
agent test freeze binds the unchanged initial freeze and both models' fitted
artifacts. Fitting still rejects all test and correction rows. The fixed monitor
policy is unchanged. No test output is used to choose prompts, cases, layers,
thresholds, regularization or allocation seeds. Every failure remains recorded.

An agent audit cannot be passed to the human route, and a human freeze cannot
authorize exploratory fits as if they came from the same review pathway.
Train/test provenance must agree. Existing failed qualification gates and old
results remain untouched.

Later human review cannot retrospectively turn exposed exploratory outcomes
into confirmatory results. Repeating this same bank after human review is an
exposed-case rerun. If exploratory outcomes motivate changes to cases, prompts,
methods or hypotheses, any later confirmatory claim requires a separately
frozen fresh cohort and a prospective analysis plan before its outcomes.

## What the result can establish

The matched comparison tests the effect of fitting support on these pipelines:
restricted I!=U examples versus a mixture containing I=U and I!=U, with matched
budgets and groups. Both arms see full-support development labels for shared-C
selection; this is not zero preserving-example exposure across the pipeline.
Train-only scalers also differ, so a gain concerns fitted pipelines, not isolated
classifier coefficients or causal changes inside the language model.

Correction sequences also differ in length and event count. Their same-format
secondary cells help diagnose failure but do not isolate an abstract composition
mechanism. Narrative-group intervals are conditional on this authored bank and
shared renderer; factorial rows and five allocations are not extra independent
reasoning families. Two separately fitted models provide replication, not proof
of universality. Second-order belief probing itself already has prior art.

A defensible report includes both absolute arm scores, the predeclared quartet
contrast and uncertainty, same-mechanism retention, secondary correction cells,
strong text/output baselines, invalid/failure rates, model-specific results,
and the absence of human validation. No positive effect, paper acceptance,
mark or admission outcome is guaranteed by this design.
