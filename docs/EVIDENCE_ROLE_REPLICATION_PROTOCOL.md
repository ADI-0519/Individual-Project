# One independent-reader replication of evidence-role substitution

20 November 2026. This is a **post-discovery replication** of the completed Qwen
96-condition evidence-role diagnostic. It was not part of an originally
preregistered two-model study. There is one independently specified checkpoint
and no model, policy, example, output-budget or case search.

Reuse **all 96 ordered messages and normative job metadata verbatim** from the
completed discovery protocol. Verify its manifest, protocol, combined rows,
per-call records and reproducible summary, plus all originally frozen current
source-file hashes. Preserve the discovery directory byte-for-byte. Do not
reauthor cases, exclude failures or select examples by their Qwen outputs.

The system and nine demonstration message pairs remain textually identical.
The source Qwen policy metadata identifies where those messages came from;
it does not mean Llama inherits Qwen's checkpoint identity or a qualification.
The replication is a diagnostic, with `qualifies_reader=false`, zero new probe
fits and zero untouched `ct` calls.

Use only `meta-llama/Llama-3.1-8B-Instruct`, revision
`0e9e39f249a16976918f6564b8830bc894c89659`, NF4 weights/BF16 compute, CUDA,
local cached files, the existing block-8 configuration and 2,048-token context
allowance. No activations are captured. Generate greedily with seed 42 and the
unchanged eight-token budget. Reuse the discovery's strict EOS parser and exact
summary definitions, retaining every invalid and capped output.

Freeze the full replication job list, requested model settings, discovery-tree
hashes and replication code/protocol hashes **before model loading**. Preflight
all 96 prompts using Llama's own pinned tokenizer and chat template. Save those
token IDs and reject overflow without truncation. Every generated call must match
its own exact preflight prompt IDs. Qwen and Llama token IDs need not match; their
input message strings must match. Do not compare unlike tokenizer coordinates as
an exact cross-model replay.

Save every call and the combined rows, summary, model/runtime metadata and
artifact hashes in a new output directory. Preserve failed attempts. Any source,
model-identity or prompt-ID mismatch stops the replication. Verify the discovery
tree remains unchanged at completion and failure cleanup. Report all conditions
and the same case-cluster contrasts, without calling the same 16 cases a new
content holdout or treating repeated conditions as independent scenarios.

Compare models descriptively on decisive evidence, administrative metadata,
explicit-missing conditions, paired value following and deferral changes. Two
checkpoints and two authored grammars cannot establish prevalence across models
or domains. Success or failure does not change the failed reader gate, authorize
dependent outcome-probe training, demonstrate an internal causal mechanism or
establish novelty. Interpret the pattern alongside the discovery's controls and
the earlier failed communication measurements.
